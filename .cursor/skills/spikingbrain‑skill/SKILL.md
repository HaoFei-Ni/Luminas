# Luminas-Arch-Skill 强制工作约束

## 一、项目定位
本项目 Luminas 为**全新独立创新架构项目**，基于SpikingBrain2.0技术底座独立开发。核心提出**新型无损KV缓存压缩机制**，区别于传统量化、剪枝、稀疏化等主流压缩范式；仅参考SpikingBrain、Falcon-H1、Mamba-3、Ouro等现有技术思想，产出原生全新实现，不属于任何上游仓库的二次改造分支。

## 二、核心技术特性
1. 完整兼容 Transformer 范式与标准注意力机制，可无缝对接主流训练推理生态；
2. 融合多套前沿架构的核心能力，所有技术术语对齐官方论文定义：
    - **Falcon-H1**：混合注意力-SSM架构，全局注意力兜底长上下文召回，同参数量级下峰值推理性能与混合架构表达域优势；
    - **Mamba-3**：超长序列线性复杂度，MIMO状态空间与硬件感知并行扫描优化，大批次Prefill吞吐优势；
    - **SpikingBrain2.0**：脉冲稀疏事件驱动，面向端侧低功耗与神经形态硬件适配；
    - **Ouro**：参数共享循环架构（Looped Architecture），计算深度与参数量解耦，小模型参数效率优势；
3. **核心原创创新点：新型无损KV缓存压缩架构**
    - 区别于传统量化、剪枝、稀疏化、低秩分解等常规压缩方案；
    - 严格保证模型精度与端到端推理效果零退化，实现高性能缓存压缩比与超长上下文吞吐提升；
4. 面向超长上下文场景，按照顶刊级标准设计可消融、可复现的完整实验体系。

## 三、架构分层强制规范
严格执行四层分离架构，各层职责清晰，对齐行业主流技术栈与顶级工程范式：
1. **核心计算内核层**
    - 技术栈：ANSI-C(C99，CPU基准内核)、CUDA-C++(NVIDIA GPU算子)、Triton(高层GPU算子)
    - 职责：实现纯数值计算逻辑，所有内核可独立编译、独立单元测试
    - 对齐参考：Falcon-H1、Mamba-3、SpikingBrain2.0 核心算子均为本层实现
2. **语言绑定层**
    - 技术栈：pybind11 C++
    - 职责：完成 Python 与 C-ABI 之间的数据编组、参数合法性校验、异常转换
3. **上层调度层**
    - 技术栈：Python / PyTorch
    - 职责：负责模型流程调度、接口封装、训练推理入口、测试入口
    - 对齐参考：Ouro 原生纯PyTorch实现、其余项目上层调度均为本层
4. **外围基础设施层（可选，对标OpenAI GPT服务端工程范式）**
    - 技术栈：Rust
    - 职责：承载高性能推理服务运行时、分布式KV缓存运行时管理、请求调度与并发控制、高性能序列数据预处理、构建工具链与基准测试框架；聚焦内存安全、高并发与低延迟，支撑无损KV压缩的落地性能与超长上下文吞吐效率

## 四、工程与测试底线原则
1. **代码隔离原则**：所有项目原生源码统一置于 `./lumina/` 目录；外部参考仓库仅作只读查阅，禁止直接修改、打补丁式修改
2. **测试强制覆盖**：所有模块必须覆盖三类测试——单元正确性测试、边界鲁棒性测试、性能基准测试
3. **数值正确性基准**：所有计算内核必须配套FP64参考实现做数值校验，误差必须符合预设阈值；无损类算法必须满足数值一致性要求
4. **可复现构建标准（对齐Nature期刊要求）**：
    - 全依赖版本锁定，包含编译器、CUDA版本、驱动版本与第三方依赖
    - 随机种子与计算确定性全固定，支持完整复现数值结果
    - 内核全链路编译可单命令执行，实验环境可完整复现

## 五、顶刊级科研实验准则
1. **消融实验单变量控制**：每次实验仅改动一个变量，基线全程固定；必须设置基线对照组，证明增益来自创新点本身
2. **无损性严格验证**：
    - 必须同时提供「逐元素误差统计与分布」与「PPL退化量+端到端任务性能」双重无损证明；
    - 必须与传统主流压缩方案（量化、低秩、稀疏化）做横向对比，验证本方案的无损性优势；
3. **指标完整性要求**：实验必须同时报告精度、吞吐、显存峰值、计算效率四类核心指标；基准测试多次运行取均值与标准差，禁止选择性上报最优数据
4. **长上下文梯度验证**：超长上下文能力必须按序列长度梯度测试，禁止仅报告单点最优结果

## 六、产出标准
1. 所有代码产出具备科研级可复现原型质量，禁止生成仅用于演示的玩具代码；
2. 标准产出包含：模型实现、评测脚本、可复现实验配置、LaTeX图表/三线表模板，适配Nature投稿规范；
3. 实验数据与代码提交哈希一一对应，全程可追溯、可复现。
