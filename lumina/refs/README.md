# refs/ — 参考文献与参考资料

| 子目录 | 内容 | 维护约定 |
|---|---|---|
| `papers/` | 参考论文（按领域分类） | 每篇条目含 bib + 本地/URL 链接 + 一段"在 Luminas 中角色" |
| `specs/` | 技术规范（CUDA、IEEE 754 等） | 标注官方版本号与适用条款 |

## 约束

- `refs/` 只放**外部材料与原文**。Luminas 自己的标准见 `../docs/`，实验归档见 `../experiments/`。
- 论文中的方法若要成为 Luminas 对照/参考，须在 `../docs/res/` 或 lab log 中登记其角色（baseline / reference idea / 只读研究）。
